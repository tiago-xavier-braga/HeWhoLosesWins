# He Who Loses Wins

Checkers variant where whoever loses all their pieces wins. Godot 4.7 (GL Compatibility), 2D, web build for itch.io/CrazyGames.

- Game design: `docs/gdd.md`. Plan: `docs/roadmap.md`. Keep all project docs in `docs/`.
- Stay inside the current roadmap phase; new ideas go to the backlog, not code.
- Must run in a web export: no threads, no native-only APIs.
