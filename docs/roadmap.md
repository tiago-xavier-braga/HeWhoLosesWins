# Roadmap

This is a project to create a web game that will be published on third-party sites such as itch.io, CrazyGames, and others.
All the documentation for the project should be kept in the project's docs folder.

## Phase 1 
- [x] Create the project base and set up the default settings;
- [x] Create mechanics to control the pieces using placeholder art
- [x] Create a rule for whose turn it is
- [x] Create a rule for when a player wins the match

- [x] Export the project for a web build
## Phase 2

- [x] Create the CPU mechanics with 3 levels (easy, medium, hard)
- [ ] Create the puzzle mechanics
- [ ] Create a web build

## Phase 3

- [ ] Create the final art and import it into the project
- [ ] Create the UIs
- [ ] Import the sound files and add them to the project

## Phase 4

- [ ] Create as many levels as possible (minimum 15)
