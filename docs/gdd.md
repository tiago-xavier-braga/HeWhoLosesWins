# GDD

## Pitch

A checkers game where whoever loses wins. You have to lose your pieces.

## Overview

- **Genre:** Digital card/board game
- **Art:** 2D Minimalist
- **Platform:** Web build (itch.io)
- **References:** Checkers, Giveaway checkers (anti-checkers variant)
