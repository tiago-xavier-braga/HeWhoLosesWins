# He Who Loses Wins

A checkers game where whoever loses wins. You have to lose all your pieces.

Built with Godot 4.7 (GL Compatibility) as a 2D web game, to be published on itch.io, CrazyGames and other sites.

## Run

1. Install [Godot 4.7](https://godotengine.org/download).
2. Open `project.godot` in the editor.
3. Press F5 to play.
